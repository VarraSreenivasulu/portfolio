Indian House Price Prediction App Serves Real-Time Valuations Nationwide

By Varra Sreenivasulu · ML Engineer · Deployed Live on Railway

In a landmark project for the Indian real-estate sector, Varra Sreenivasulu engineered a full end-to-end ML pipeline processing an astounding 2,50,000 Indian property listings. The system, built entirely in Python with Scikit-learn, is deployed live on Railway platform and accessible to anyone seeking property valuations.


The project rigorously evaluated four machine learning models — Linear Regression, Ridge Regression, Decision Tree, and Gradient Boosting — measuring accuracy through MAE, RMSE, and R² metrics to select the optimal predictor. The culminating achievement: a Flask REST API with a /predict endpoint delivering real-time price predictions via a responsive web dashboard.
